## Release gates

1. No result is labeled “method-compliant,” “verified,” or “issued” until the controlled calculation and evidence have passed independent methodology/VVB review.
2. Each equation branch has a known-answer test, boundary/invalid-input tests, and an API test that confirms evidence and project access rules.
3. Migration, backend tests, frontend tests/build, and an end-to-end staging run pass on a production-like database and realistic, authorized project data.
4. External integration is enabled only after the provider API contract and credentials are supplied through the deployment secret store and sandbox reconciliation succeeds.
5. Retain methodology version, source links/checksum, calculator version, input snapshot, field/data provenance, reviewer, and decision with every published result.
